# 资产配置助手 · Asset Allocation Advisor

一个面向**普通投资者**的 AI Agent Skill：把「钱该怎么放」这种模糊、焦虑、信息不全的日常提问，
翻译成**看得懂、做得到、能检查、可修正**的资产配置方案。

> 它不预测市场，不挑产品，不承诺收益。它做的是：把问题问对，把约束列清，把方案写成能执行、能复盘的样子。

---

## 它解决什么

普通投资者真正卡住的地方，通常不是「不知道买什么」，而是：

- 目标模糊或互相冲突（既要安全又要高收益，还要随时能取）；
- 把「敢亏」当成「亏得起」，把「想赚钱」当成「必须冒险」；
- 只看金融账户，忽略家庭负债、收入行业和应急资金；
- 把产品种类当成资产类别，把买得多当成分散；
- 用历史收益、短期排名推断未来；
- 一跌就想补仓翻本，一涨就追高，没有再平衡规则；
- 方案太复杂，写出来很漂亮，执行两周就放弃。

这个 Skill 把这些「难点」变成一份**自动诊断清单 + 结构化输出**，让对话直接落在可执行的动作上。

## 怎么用

### 方式一：装成 Agent Skill（推荐）

把 `SKILL.md` 放到你的 Agent 技能目录，例如 WorkBuddy / Claude Code：

```bash
# WorkBuddy（用户级）
git clone https://github.com/<your-name>/asset-allocation-advisor.git \
  ~/.workbuddy/skills/asset-allocation-advisor

# Claude Code（用户级）
git clone https://github.com/<your-name>/asset-allocation-advisor.git \
  ~/.claude/skills/asset-allocation-advisor
```

装好后直接用日常语言提问即可，不需要记任何指令：

- 「我手上 30 万，五年后可能买房，现在全在活期，该怎么放？」
- 「基金跌了 15%，是不是该加仓把亏损赚回来？」
- 「我有 8 只基金，是不是已经够分散了？」
- 「明年可能要结婚，现在的配置要不要动？」

### 方式二：当纯提示词用

不装 Skill 也行：把 `SKILL.md` 里 `---` 之间的元信息删掉，正文整段粘贴进任意大模型对话的开头，
然后正常提问。

## 输出长什么样

默认输出五个可选模块，按问题复杂度裁剪，不硬凑长度：

| 模块 | 作用 |
|---|---|
| 【我对问题的理解】 | 一句话说清你真正要解决的问题（简单问题可省略） |
| 【关键判断】 | 最重要的 2—4 点，含原因、适用条件、主要风险 |
| 【可以怎么做】 | 按优先级排列的可执行步骤，优先给不依赖市场预测的动作 |
| 【还需要补充】 | 最多 3 个最关键的问题；不回答也能保留当前情景分析 |
| 【复盘条件】 | 哪些生活变化、资金需求或组合偏离需要重新检查 |

### 四种特殊指令

| 你说 | 它做 |
|---|---|
| 「只优化提示词，不要回答」 | 把你的描述整理成一段可独立复制的完整提示词，缺失变量标 `【待补充】` |
| 「直接回答」 | 列出假设，直接给条件式分析，不再追问 |
| 「逐步带我分析」 | 每轮只谈一个主题、最多问 3 个问题，按你的回答往下推 |
| 「汇总」 | 输出《个人资产配置政策书》：目标 / 财务约束 / 风险约束 / 配置区间 / 流动性安排 / 执行规则 / 再平衡 / 行为预案 / 评价方式 / 信息缺口 / 复核条件 |

## 设计原则

1. **先约束，后收益**：目标、期限、流动性在前，收益和产品在后。
2. **三分风险**：敢亏（意愿）、亏得起（能力）、是否必须冒险（必要性），不可互相替代。
3. **区间而非点值**：给宽资产类别的比例区间和适用条件，不制造「唯一最佳比例」。
4. **可执行优先**：动作优先选不依赖市场预测的那一类（如先补应急金、先还高息负债、先定再平衡规则）。
5. **不编造**：缺什么标「待补充」，不替用户补写事实，不猜产品持仓与费率。
6. **情绪优先处理**：遇到急用钱、借钱投资、杠杆平仓、急于翻本，先谈流动性，不谈收益最大化。

## 边界与免责

- 本 Skill 只做**投资者教育与决策梳理**，不构成投资建议、不构成任何产品推介。
- 不预测市场，不提供收益预测或数值承诺，不推荐具体标的。
- 涉及具体产品时，请以合同、招募说明书、定期报告和销售机构的正式文件为准。
- 所有配置比例均为**示意区间**，实际执行前应结合自身情况与持牌专业人士意见。
